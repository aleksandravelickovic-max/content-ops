## 1. Brand & Audience

Liveops is a cloud-based workforce solutions company that connects enterprises with an on-demand network of independent agents. Founded 25+ years ago, Liveops serves Fortune 500 companies and mid-to-large enterprises with $100M–$1B+ in revenue.

Website: https://liveops.com/

**What Liveops is:**
- A marketplace and management platform for flexible, remote customer service agents
- A workforce solution that enables enterprises to scale support capacity up or down without fixed headcount
- A provider of omnichannel customer service (voice, chat, email, text) across industries

**What Liveops is NOT — never position as:**
- A call center
- A CCaaS (cloud contact center as a service) platform
- A staffing agency
- A traditional outsourcing company

**Target audiences:**

**Verticals served:** Retail and ecommerce, healthcare, financial services, insurance, travel and hospitality.

## 2. Brand Voice & Tone

Voice: confident, strategic, direct, human. Liveops speaks to enterprise leaders who have already seen traditional outsourcing fail. Content should feel like a peer conversation between CX professionals, not a vendor pitch.

| Attribute | Rule |
|---|---|
| Confident | State facts. No hedging language unless accuracy requires qualification. |
| Direct | Lead with the business outcome, then explain how. No throat-clearing. |
| Strategic | Frame everything in terms of business impact, not features. |
| Human | Avoid corporate stiffness; write for real decision-makers, not procurement bots. |
| Precise | Exact terminology matters here — especially around agents. See §3. |

### 2.1 Tagline

**"It's not outsourcing, it's outsmarting."**

Use this in brand-level content where positioning against traditional outsourcing is relevant. Do not force it into every piece.

### 2.2 Voice in practice

Do this:
- "Agents within our network become certified to handle your specific program before their first interaction." — accurate, compliant, human
- "Liveops scales capacity in hours, not weeks — without adding headcount." — outcome-forward, specific
- "The Liveops model replaces fixed staffing costs with a flexible, usage-based structure." — clear business framing

Not this:
- "Our team of Liveops agents is trained and ready to help." — violates agent language rules (team, Liveops agents, trained)
- "We hire top-tier customer service talent for your brand." — violates agent language rules (hire, talent as hiring framing)
- "Liveops is a leading CCaaS platform." — prohibited positioning
- "Our cutting-edge, world-class call center solution..." — generic superlatives; also prohibited as "call center"

### 2.3 Sentence and paragraph rules

- Paragraphs: 2–4 lines maximum. One idea per sentence.
- First sentence of every section directly answers the heading.
- No em dashes. Restructure or use a period.
- Lead with business outcomes; follow with mechanism.
- Do not start sections or paragraphs with a hyperlink.

### 2.4 Banned language (general)

| Category | Banned |
|---|---|
| Positioning violations | call center, CCaaS, staffing agency, outsourcing (without "outsmarting" reframe) |
| Agent language violations | See §3 — extensive list; any violation is a legal/compliance error |
| Generic superlatives | world-class, best-in-class, leading, cutting-edge, innovative, seamless |
| AI filler | in the world of, as we know, it's worth noting, delve into, dive into, furthermore, in conclusion |
| Filler intensifiers | truly, really, simply, of course, literally, incredibly |

## 3. Agent Language — Critical Compliance Rules

**These are legal requirements, not style preferences.** Incorrect agent language has regulatory implications due to independent contractor classification. Every piece of content must pass this check before publication.

### 3.1 Agent relationship framing

Liveops agents are independent contractors, not employees. Content must never imply an employment relationship.

| Never use | Always use instead |
|---|---|
| hire / hiring agents | agents join our network / agents become part of the network |
| employee / employees | agent / agents |
| associate / associates | agent / agents |
| partner (for agents) | agent / agents within our network |
| work for Liveops | provide services through the Liveops platform |
| staff on / staffed | placed, deployed, certified for a program |
| our agents / Liveops agents | agents within our network / our network of agents |
| team / our team (for agents) | network / the Liveops network |
| family / our family | network |
| workforce (when implying employment) | network; agent pool |
| gig (as a descriptor for Liveops work) | flexible remote work; independent contractor opportunity |
| VirtualFlex | do not use — retired term |
| right-time scheduling | precision scheduling |
| training | certification; becoming certified |
| CCaaS | do not use |

### 3.2 Approved agent status terms

| Approved | Never use |
|---|---|
| active | employed, working |
| contracted | hired |
| inactive | terminated, fired |
| source | recruit |

### 3.3 How to talk about agents doing things

| Never write | Write instead |
|---|---|
| Agents are trained by Liveops | Agents become certified through the Liveops platform |
| We train agents to handle... | Agents complete certification to handle... |
| Liveops agents work on your account | Agents within our network provide services for your program |
| We hire the best agents | Agents who join our network meet [criteria] |
| Agents schedule shifts | Agents schedule themselves using precision scheduling |
| Our agents are ready | Certified agents within our network are available |

### 3.4 Approved external-facing terms

These terms are cleared for public content:

| Term | Usage note |
|---|---|
| remote | Preferred over "virtual" for agent work location |
| customer service / customer support | Core service description |
| flexible / scalable / agile | Use in this priority order |
| modern customer service model | Approved positioning phrase |
| empathetic support | Approved service descriptor |
| certified / certification | Approved for agent qualification language |

### 3.5 Context-only terms (use sparingly)

These terms may appear for SEO or character-limit purposes but must not define the brand:

| Term | Constraint |
|---|---|
| CX | Abbreviation only; do not use "CX company" as a descriptor |
| call center | May appear in keyword context (e.g., "alternative to a call center") but never as self-description |
| contact center | Same constraint as "call center" |
| on-demand | Use only in context of workforce model, not as a brand label |

## 8. Page Templates

### 8.1 Blog posts

Target length: 800–1,500 words.

Structure:
1. Meta title (55–60 characters): primary keyword near front; include "Liveops" where natural
2. Meta description (140–160 characters): primary keyword, business outcome, brand name
3. 3 primary keywords defined
4. H1: direct, keyword-forward; answers the CX leader's question without clickbait
5. Short intro (2–3 sentences): state the problem and what the piece covers; no filler
6. H2 sections: each a distinct business question; first sentence directly answers the heading
7. H3 for subsections; no H4 unless deep reference content
8. Closing CTA: specific, action-based; no generic "learn more" framing
9. Agent language check required before publishing (see §3)

### 8.2 Service pages / solution pages

Structure:
1. H1: primary keyword; outcome-first framing
2. Problem paragraph (2–4 sentences): the pain state the page addresses
3. How Liveops solves it (2–4 sentences): mechanism, not just claims
4. Key capabilities or differentiators (3–5 bullet points or a table)
5. Industry fit (where relevant)
6. CTA: specific next step (demo, consultation, contact)
