# Liveops — Agent Speak Doc

Source: Agent Speak Doc v2.pptx.pdf
Ingested: 2026-06-03

This document defines approved and prohibited language for describing Liveops agents in external content. These are legal compliance requirements — violations have regulatory implications due to independent contractor classification.

---

## The Core Rule

Liveops agents are **independent contractors**, not employees. All content must avoid language that implies an employment relationship. This applies to blog posts, web pages, sales collateral, and any external communication.

---

## Agent Relationship — Approved vs. Prohibited

| Prohibited | Approved alternative |
|---|---|
| hire / hiring agents | agents join our network; agents become part of the network |
| employee / employees | agent / agents |
| associate / associates | agent / agents |
| partner (for agents) | agent / agents within our network |
| work for Liveops | provide services through the Liveops platform |
| staff on / staffed | placed; deployed; certified for a program |
| our agents | agents within our network |
| Liveops agents | agents within our network; the Liveops network |
| team / our team (agents) | network; the Liveops network |
| family / our family | network |
| workforce (employment-implying) | network; agent pool |
| gig (for Liveops) | flexible remote work; independent contractor opportunity |
| training | certification; becoming certified |
| trained | certified |
| VirtualFlex | do not use — retired term |
| right-time scheduling | precision scheduling |
| CCaaS | do not use |

---

## Agent Status Terms

| Use | Do not use |
|---|---|
| active | employed, working |
| contracted | hired |
| inactive | terminated, fired, let go |
| source | recruit |

---

## How to Describe What Agents Do

| Do not write | Write instead |
|---|---|
| Agents are trained by Liveops | Agents become certified through the Liveops platform |
| We train agents to handle... | Agents complete certification to handle... |
| Liveops agents work on your account | Agents within our network provide services for your program |
| We hire the best agents | Agents who join our network meet [criteria] |
| Agents schedule their shifts | Agents schedule themselves using precision scheduling |
| Our agents are ready | Certified agents within our network are available |
| Agents are staffed on programs | Agents are certified for and placed on programs |

## Approved External-Facing Terms

These are cleared for public content:

| Term | Usage note |
|---|---|
| remote | Preferred over "virtual" for agent work |
| customer service / customer support | Core service descriptor |
| flexible / scalable / agile | Use in this priority order |
| modern customer service model | Approved brand phrase |
| empathetic support | Approved service descriptor |
| certified / certification | Approved for agent qualification language |
| precision scheduling | Approved replacement for "right-time scheduling" |

---

## Context-Only Terms

These may appear for SEO or character-limit purposes. Do not use to define the brand:

| Term | Constraint |
|---|---|
| CX | Abbreviation only — never "CX company" as a descriptor |
| call center | Keyword context only (e.g., "alternative to a call center") — never as self-description |
| contact center | Same constraint as "call center" |
| on-demand | Use only in workforce model context — not as a brand label |

---

## Quick Check Before Publishing

Ask these questions about any piece of content:

1. Does the content use any prohibited agent terms from this document?
2. Does any sentence imply agents are employees, hired, or trained (not certified)?
3. Does the content describe Liveops as a call center, CCaaS, or staffing agency?
4. Are agents referred to as "our agents" or "Liveops agents" instead of "agents within our network"?

If any answer is yes — revise before publishing.
