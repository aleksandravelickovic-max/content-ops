# Altify Content Directory

This directory contains messaging, product notes, persona briefs, templates, and page drafts for Altify content production.

Altify is the Account Planning AI Cloud for enterprise revenue teams. The company combines Salesforce-native software, AI-enhanced workflows, sales methodology, relationship intelligence, account planning, opportunity management, and revenue enablement services.

Core content goals:
- Position Altify as a Salesforce-native revenue execution and account planning platform.
- Speak directly to enterprise revenue personas.
- Connect methodology, execution, coaching, data quality, and predictable growth.
- Avoid generic AI language.
- Keep content practical, strategic, and outcome-focused.

---

## Editorial QA Checklist

Before finalizing any Altify page, check:

- [ ] Does the H1 include the primary keyword?
- [ ] Does the primary keyword appear the required number of times?
- [ ] Are secondary keywords inserted naturally?
- [ ] Does the page speak to one clear persona?
- [ ] Are the pain points specific to that persona?
- [ ] Does the solution section map clearly to the pains?
- [ ] Are headings not copied directly from guidelines?
- [ ] Is Altify speaking in first person plural where appropriate?
- [ ] Are claims grounded in business outcomes?
- [ ] Is Salesforce-native positioning clear?
- [ ] Are FAQs adding new value instead of repeating the page?
- [ ] Are meta title and meta description within character limits?

## Meta Description Rules

- 150–160 characters
- Include the primary keyword
- Mention Altify
- Include one clear business outcome

Example pattern:
> Altify is a [PRIMARY KEYWORD] that helps [persona/team] [main action] in Salesforce, improving [outcome] and [outcome].

## Notes for Claude Code

When generating new Altify content:

1. Read the relevant persona file.
2. Read the product file if the page is product-specific.
3. Use the persona landing page template.
4. Insert the required keywords exactly according to instructions.
5. Use first-person plural when Altify is the speaker.
6. Do not copy guideline sentences verbatim.
7. Keep the page concise but complete.
8. After drafting, run the keyword and editorial checklist.
