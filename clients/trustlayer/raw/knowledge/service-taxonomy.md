# TrustLayer Service Taxonomy

Source: STYLE-SYSTEM.md, refreshed website intelligence, and local client research.

## Platform Features

- Automated COI Collection: Vendors submit certificates of insurance directly without a vendor sign-in requirement.
- AI Gap Detection: Automated review that flags missing or non-compliant coverage.
- Multi-Document Support: Document support for COIs, W-9s, business licenses, and contracts.
- Automated Renewal Reminders: Vendor reminders before compliance documents expire.
- Real-Time Compliance Monitoring Dashboard: Dashboard for current vendor compliance status across documents.
- API and Integrations: Connections into existing workflows through API and integration support.
- TrustScore: Proprietary risk scoring metric used in the TrustLayer platform.
- W-9 Form Collection: Automated W-9 collection, validation, and data extraction.

## Industries Served

- Construction: COI and compliance tracking for construction vendor and subcontractor workflows.
- Property Management: Compliance document tracking for property vendors and service providers.
- Insurance: Document collection and risk workflows for insurance-related teams.
- Logistics: Vendor and compliance document workflows for logistics operations.
- Retail and Distribution: Compliance document workflows for suppliers, vendors, and distributed operations.
