# Atlas Coworker

## What it is

Atlas Coworker is Search Atlas's workspace integration layer. It brings Atlas Agent capabilities into the messaging and project management tools where marketing teams already work: Slack, Microsoft Teams, and ClickUp.

Atlas Coworker is an extension of Atlas Agent (the conversational AI inside the Search Atlas dashboard). The same agent that executes inside the web platform is accessible from a Slack thread, a ClickUp task, or a Teams channel. Teams do not need to switch contexts to run marketing operations.

## What it can do

- Execute any action available through Atlas Agent and OTTO SEO from inside a chat thread
- Connect to 3,000+ external tools via native connectors: HubSpot, Salesforce, Meta Ads, TikTok Ads, LinkedIn Ads, Twitter Ads, Google Calendar, Google Drive, GitHub, GitLab, Vercel, Intercom, and more
- Retrieve and analyze data from connected platforms (e.g., pull HubSpot contact counts, segment breakdown, email performance)
- Generate and deploy marketing assets (ad creative, web pages, content) from a conversation thread
- Run scheduled automations (routines) — e.g., daily Slack summary of campaign performance at a set time
- Execute Search Atlas Playbooks on a schedule
- Maintain persistent memory across conversations — remembers team context, recurring meetings, positioning decisions
- Supports mobile marketing: works via phone through messaging apps, no desktop required

## Self-healing loop (Multiplayer Marketing)

Atlas Coworker is the execution layer for the Multiplayer Marketing thesis:

1. **Sense** — Watches live marketing surfaces alongside the current brand strategy
2. **Detect** — Identifies where a surface (ad copy, landing page, GBP listing) has drifted from current positioning
3. **Propose** — Drafts the corrective copy or creative aligned to where the business is now
4. **Approve** — Human reviews and gates every change before it ships (nothing goes live unseen)
5. **Heal** — Updates the live surface; resumes monitoring

This loop runs continuously rather than requiring a human to notice drift.

## Workspace admin controls

- Workspace admins can share connectors across the full team (e.g., one HubSpot account accessible to everyone) or restrict to personal use only
- Per-channel access controls: external users can be granted or denied access to specific Slack channels
- All settings managed from Search Atlas dashboard: Settings → Messaging Gateways
- Individual users can override shared connectors with their own credentials where needed

## Pricing and credit model

Atlas Coworker is included in the Search Atlas subscription — not a separate purchase. AI execution consumes Universal Credits from the shared credit bank. The Universal Credit system replaces per-feature quotas; credits can be topped up and applied to any tool or action. Cost per action decreases over time as Search Atlas optimizes infrastructure. The intent is that Atlas Coworker performs proactive work on behalf of users, so credit costs trend down to support higher consumption volume.
