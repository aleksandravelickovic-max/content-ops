## Headline

The content already exists. The problem is routing and discoverability, not missing topics. Search Atlas has a deep, published AEO/GEO/AI-visibility blog cluster (20+ posts), but the posts do not route readers to the LLM Visibility tool and are not internally linked into a hub. Organic readers landing on AEO content rarely reach the tool, which explains "heavily used but hard to find" without any content gap.

Recommendation: stop briefing net-new topics. Run a routing-and-linking fix across the existing cluster. It is faster, cheaper, and targets the actual problem.

## The three real problems (consistent across sampled posts)

Sampled: what-is-answer-engine-optimization, how-to-win-ai-visibility, how-to-use-search-atlas-llm-visibility. The pattern repeated in all three.

### 1. No tool-specific CTA — only generic "Try Search Atlas"

The LLM Visibility tool is named once per post, usually mid-body, with no clickable CTA next to it. The only CTAs are a generic "Try Search Atlas" button linking to dashboard registration. A reader who just read about measuring AI visibility is not pointed at the LLM Visibility tool specifically; they get a generic homepage-style signup.

Fix: add a tool-specific CTA ("Track your brand's AI visibility in Search Atlas") adjacent to every LLM Visibility mention and at section end, deep-linked to the tool, on the measurement-intent posts first (how-to-win-ai-visibility, brand-ai-visibility, the two research companions).

### 2. Internal links point to the wrong cluster

The AEO/GEO/AI-visibility posts cross-link to the unrelated "AI CMO" content cluster in their "Related Reads," not to each other. The AEO/GEO cluster is a set of orphans with no internal pathway between related posts and no link equity flowing between them.

Fix: re-map "Related Reads" and in-body links so AEO/GEO/AI-visibility posts link to each other and to the tool walkthrough. Stop linking this cluster to AI CMO.

### 3. No hub / pillar page

There is no pillar tying the cluster together. The product walkthrough (how-to-use-search-atlas-llm-visibility), which is the natural conversion asset, is self-contained and not linked from the education posts, so warm-intent readers never find it.

Fix: build an "AI Search Discoverability" hub page linking the whole cluster, with the LLM Visibility tool and the walkthrough as the conversion center. Link every cluster post up to the hub and the hub down to each post.

## Secondary flag (verify)

Naming inconsistency: one post calls it "QUEST LLM Visibility tool," others "LLM Visibility." Confirm the canonical product name and standardize across the cluster. (STYLE-SYSTEM §3 lists Content Genius, OTTO, Scholar, etc.; LLM Visibility / QUEST naming is not pinned there.)
