## How to share or export

**Email / Drive / Slack.** Zip the folder and send it. Recipient opens `index.html` in any browser.

```bash
zip -r zia-knowledge-site.zip zia/knowledge-site -x "*.py" -x "*.md"
```

**Host on Netlify or GitHub Pages.** Drag the folder onto Netlify, or push it to a `gh-pages` branch. The site is fully static.

**Print or PDF.** Each page has a print stylesheet that hides the sidebar and reflows for letter-size paper. Use the browser's *Print → Save as PDF*.

**Open offline.** Double-click `index.html`. Pages link to each other with relative paths, so it works without a server. (Google Fonts loads from a CDN; system serif/sans fallbacks are styled to look reasonable if offline.)

## Rebuilding from source

If any of the source markdown files change in `knowledge/products/zia-tile/` or `zia/README.md`, regenerate from the repo root:

```bash
python3 zia/knowledge-site/_build.py
```

Requires Python 3.9+ and the `markdown` package (`pip install markdown`).

Note: `style-guide-v3.html`, `jamie-feedback.html`, `clickup-channel-recap.html`, and the three Reference Content pages (`blog-4-cotto.html`, `collection-cotto.html`, `product-red-clay-8x8.html`) are hand-authored HTML and are not regenerated by `_build.py`. Edit them directly or regenerate from source PDFs.

## Notes

- Repo-only links (paths into `briefs/`, `drafts/`) are rendered as plain text with a `(repo only)` tag, since those files don't ship with the export.
- External URLs (Google Docs, public articles) work as normal links.
- Sidebar nav is duplicated in each HTML file — when adding a new page, update every sibling page.
