# Zia Tile Editorial Style Guide v2.0 (April 2026)

Source of truth for all Zia Tile product page copy. Where prior sources conflict, **client revisions take precedence**.

★ marks content new in v2.0.

## 1. Brand & Audience

- LA-based retailer of handmade artisanal tile and stone, ships worldwide.
- Two audiences must both be respected: **Trade (55–60% revenue)** — architects, designers, contractors, installers managing $20k–$80k+ projects; need technical precision and no hand-holding. **Homeowners/Business owners (40–45%)** — affluent first-time buyers, ages 30–60; need clear guidance and confidence-building detail.
- Brand pillars: **Authoritative, Artisanal, Approachable, Inspirational**. Authority through specificity, never through adjectives. Show quality; never claim it.

## 2. Voice & Tone

- Voice: trusted senior design editor — authoritative, warm, precise.
- Test: does this read like an expert talking, or a marketer selling?
- Polished, not corporate; clear, not casual.
- Short to medium sentences. One idea per sentence. Active voice.
- **No fragments anywhere** in body copy or bullets. Complete sentences only.
- Remove filler: `truly`, `really`, `simply`, `of course`, `unique` (without context).
- Atmosphere comes from precise nouns and active verbs, not stacked descriptors.
- Lead with the fact; let the customer draw the conclusion.
- Anchor atmospheric/historical claims in a specific noun (e.g. "in mosaics featuring decorative geometric and floral shapes").
- The "purposeful test": if removing the sentence loses nothing, cut it.

## 3. Terminology

### 3.1 Required terms

| Term | Use |
|---|---|
| Inherent / innate variation | Frame variation as a defining characteristic, not inconsistency |
| Dynamic glazes | For zellige glaze visual range — not "color variation" |
| Chips, pits, and crazing | Always list as a trio. Crazing = fine glaze surface lines from kiln firing |
| Perfectly imperfect | Core narrative — use in context, not as standalone claim |
| Each (not "every") | "Each tile," "each Casablanca 4x4" |

| Schluter strips | Metal edge profiles — installation-literate term |
| Shower tile / shower wall | Never "shower surround" |
| Grout joints | Never "grout spacing" |
| 15–20% overage | Always paired with the 25% option for uniform look |
| Drywall flush | Required Installation step — drywall brought flush with finished tile |

| Avoid | Use instead |
|---|---|

## 4. Accuracy & Technical Standards

**Non-negotiable:** if a capability claim isn't verifiable against the product spec or Installation Guide, do not write it. Limitations must be stated explicitly and affirmatively.

### 4.1 Freeze/Thaw

Zellige is **not suitable** for outdoor installation in freeze/thaw climates. Hard limitation. Never use "withstands" or "provides a durable option" without scoping the climate.

- Exterior floors / freeze-thaw climates → **not suitable**
- Exterior walls → **may be used in non-freeze/thaw climates** only

### 4.2 Sealing Requirements

- Sealing guidance must appear **inline within the specific usage bullet** (shower, pool, spa) — not only in a section-end catch-all.
- Section-end "Sealing Required" line is a backup, not a substitute.
- Direct readers to the Zellige Installation Guide for sealer selection. Never name a specific product.
- ★ **Dry spaces also require sealing.** Use this exact wording: *"Always seal [tile name] according to our installation instructions, whether in dry spaces or in areas exposed to moisture, such as pools, spas, and showers."*

### 4.3 Slip Resistance

For wet floor recommendations, always specify: **minimum ⅛" grout joint and/or anti-slip product after installation.** Never just "consult your installer."

### 4.4 Installation Section — Required Elements

Every Installation and Finishing section must include all four:
1. **PPE + Prop 65 warning** — protective face/eye coverings when working with zellige, thin set, sealants, grout. Link to ziatile.com/proposition-65-warnings.
2. **Edge / finishing options** — drywall flush + mitered edges + Schluter strips. Never "trim pieces."
3. **Sealing for moisture areas** — sealing required in all installations per Installation Guide; specifically pools, spas, showers.
4. **Contact email** — info@ziatile.com for installer questions.

### 4.5 Usage Chart Standards ★

- Usage bullets are **standardized at the category level** (e.g. Glazed Zellige). Do **not** write usage bullets from scratch per SKU.
- Substitute only SKU-specific details: format dimensions, orientation, finish-specific notes.
- Structure, wording, and bullet order must be identical across all SKUs in the same category.
- Approved category templates are maintained by Alex. Request before starting a new category.

### 4.6 Content Placement Accuracy ★

Each usage bullet must contain only information **relevant to that specific use case**. Misplaced content is a factual error.

- Shower / wet-area slip resistance → **Shower Walls + Floors** only.
- Interior Floors – High Traffic → kitchens, entryways, primary bathrooms used as **dry floors only**.
- If unsure, flag for Alex; do not guess.

### 4.7 Unglazed Zellige ★

Unglazed zellige is a **separate category** from glazed zellige. Different language for sealing, surface variation, finish-specific characteristics. Do **not** apply glazed zellige usage template or sealing copy to unglazed pages. Request category-specific guidance from Alex first.

## 6. Page Structure

### 6.1 Required sections, in this order

1. **Product Details** — variation framing (chips/pits/crazing); 15–20% overage + 25% uniform option
2. **About** — craft heritage; artisan sourcing; specific historical context; spectrum of colors for residential + commercial
3. **Inherent Variation** — three bullets: (a) color/tone with specifics, (b) uniqueness/charm, (c) full variation list (color, shape, thickness, chips, pits, crazing)
4. **Preparation and Curation** — mix boxes; lay out before installation; disperse chips/pits/variation evenly; 15–20% + 25%
5. **Installation and Finishing** — PPE/Prop 65; drywall flush + mitered edges + Schluter strips; sealing per 4.2; contact email
6. **Tile Usage** — Residential + Commercial sub-sections; accurate freeze/thaw; inline sealing for showers/pools/spas; ⅛" slip-resistance spec; correct placement (4.6)
7. **How It's Made** — raw clay from local hillsides; soaking + filtering; hand-pressing; Moroccan sun drying; hand-shaping; glaze hand-dipping; earthen kiln; uneven heat = variation
8. **Order & Shipping** — sample (2 business days, up to 10, first 5 free); full (LTL curbside, US/Canada); pickup (appointment required); contact email
9. **FAQ** — minimum 6 questions: thickness variation, shower floor installation, crazing, cleaning, characteristic features, color mixing across collection

### 6.2 Bullet rules

- One complete idea per bullet; subordinate clauses → use prose.
- Never introduce a list with a sentence that repeats the bullet content.
- Chips, pits, and crazing referenced as a trio whenever listing surface characteristics.
- Every bullet is a complete sentence.

### 6.3 Formatting

- Product anchoring: "Our Casablanca" / "Zia's Casablanca," never the color alone.
- "Each" not "every" for individual tiles.
- Bold SEO-critical phrases in the draft for client review.
- Prop 65 link → ziatile.com/proposition-65-warnings.

- **Title format:** `[Product Name] [Format] | Zia Tile` — 50–60 chars. Example: `Casablanca White Zellige Tile 4x4 | Zia Tile`

- Primary keyword in first sentence of description; never force secondary keywords.
