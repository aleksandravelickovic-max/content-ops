# Roman Mosaics — material rules

Same premium stone as Solid Marble, arranged in intricate ancient-Rome-inspired mosaic patterns. Italian stone heritage.

## Critical: Roman Mosaics DIVERGES from Marble (do NOT inherit Marble rules)

Per the Materials Reference Guide v3 Quick Reference matrix, Roman Mosaics has DIFFERENT application rules from Solid Marble in two dimensions:

| Dimension | Marble | Roman Mosaics |
|---|---|---|
| Pool/Spa | ✗ | **✓** |
| Ext Non-F/T | ✓ | **✗** |

If material-guard sees a Roman Mosaics page assert pool/spa approved, that is CORRECT. If it sees a Marble page assert pool/spa approved, that is a violation. Do not auto-fold Roman Mosaics into Marble.

## Freeze/thaw — NOT SUITABLE

Per matrix: Roman Mosaics Ext F/T = ✗. Same as Marble for freeze/thaw exteriors.

## Pools & spas — SUITABLE (selling point)

Per matrix: Roman Mosaics Pool/Spa = ✓. This IS a selling-point distinction vs Marble. Lean into it for pool tile pieces.

## Exterior non-freeze/thaw — NOT SUITABLE

Per matrix: Roman Mosaics Ext Non-F/T = ✗. This differs from Marble (which is ✓ for non-F/T exteriors). Limits Roman Mosaics to interior + pool/spa.

## Sealing — profile: natural-stone

Natural stone requires sealing. Direct readers to the Installation Guide; never name sealer products.

## Variation language

- Use: veining, tone, natural stone variation, mosaic pattern.
- Same stone family as Marble — do NOT apply zellige or terra cotta variation language.
