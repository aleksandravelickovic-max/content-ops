# Zia Tile — Colorway Reference

How Zia Tile describes the color and tone of every SKU, drawn from product pages, blog posts, meta descriptions, and image alt texts. Verbatim site language is quoted. Use this as the source of truth when describing any tile's color in copy.

---

## Universal Color Language

Zia applies a consistent vocabulary across all handmade lines:

- **"Perfectly imperfect"** — signature phrase for handmade variation
- **"Stunning variation"** — used specifically for zellige kiln-fired color shifts
- **"No two zellige tiles are exactly alike"**
- **Variation scale:** High (zellige, cotto), Moderate (limestone, cantera), Low (terrazzo, ceramics, cement)
- Lighting note: "Direct natural light brightens the tiles while shadowed installations appear deeper."
