# Zia Tile Product Page Templates — v2.0 Audit Report

**Scope:** 16 category-template drafts in the "Product Page Samples" folder, audited against the v2.0 Editorial Style Guide (April 2026) at `/knowledge/products/zia-tile/style-guide-v2.md` and cross-referenced against the 13 ziatile.com installation guides at `/knowledge/products/zia-tile/installation-guides-research.md`.

**Important framing:** these are **category templates** with placeholders ("Variable per SKU," "[KEEP]," "[CART MODULE]"), not finished SKU pages. Treating them as the source of truth for every SKU built off them per Style Guide §4.5 (Usage Chart Standards).

---

## TOP-LINE FINDINGS — apply to all 16 unless noted

### 🔴 Critical (factual or rule violations that will fail QA)

1. **Page structure does not match Style Guide §6.1.** All 16 templates collapse the 9 required sections into 6. Specifically missing as named sections: **Inherent Variation** (§6.1 #3), **Preparation and Curation** (§6.1 #4), and **Installation and Finishing** (§6.1 #5). Installation guidance is currently buried inside the **About** section, which the style guide reserves for craft heritage and historical context.

2. **The 25% overage option is missing from all 16 templates.** Style Guide §3.1 + §5 + Pre-Submission Checklist: *"Always recommend as the standard. Always add the 25% option where a more uniform look is being discussed. Both must appear together."* Every template recommends only 15–20% (or 10–15% for Doc 5 + 9). This is a Pre-Submission Checklist failure across the board.

3. **Inline sealing guidance per use case is missing (§4.2).** Style guide says sealing must appear inline within each shower/pool/spa bullet — not only in the catch-all "Sealing Required" row at the table footer. All 16 templates put a single "Sealing Required ✓" row at the bottom of the chart and rely on the catch-all. The style guide explicitly forbids that as a substitute for inline guidance.

4. **The approved §4.2 dry-spaces sealing wording is only in Docs 1 and 2 (glazed Zellige).** All other 14 docs replace it with named-product copy or omit it entirely. Style Guide §4.2 forbids naming specific products (511 Porous Plus, Fila Matte Wax) and mandates this exact phrase: *"Always seal [tile name] according to our installation instructions, whether in dry spaces or in areas exposed to moisture, such as pools, spas, and showers."* The product names belong on the install guide pages — not the product pages.

5. **Slip-resistance specification (⅛" minimum + anti-slip product) is missing from all 16 templates** (§4.3). Every template recommends Showers + Pools/Spas as ✓ but omits the wet-floor spec language. Each installation guide on ziatile.com carries the same canonical phrase: *"Slip resistance can be increased by increasing grout joint size and/or applying an anti-slip product after installation is complete."* Borrow it.

6. **No template states freeze/thaw position affirmatively in prose.** All 16 charts mark Exterior Freeze/Thaw rows but no body copy says it. For zellige (Docs 1–4), Style Guide §4.1 makes affirmative-prose disclosure non-negotiable. The freeze/thaw silence is also true of all 13 ziatile.com installation guides — so this v2.0 mandate must originate on the product page itself.

### 🟠 Major (style guide violations that will require revision)

7. **Heading hierarchy is broken in 8 of 16 docs.** Most docs nest "Commercial Usage" as `####` (H4) under a "Residential Usage" `###` (H3). Inconsistent across the set. Should be uniform `###` H3 for both.

8. **Standardized shipping copy §8.2 is paraphrased, not verbatim.** All 16 say *"Full orders ship together once all tiles are in stock"* — but the approved verbatim wording is *"We will ship the entire order together once all tiles are in stock."* §8.2 explicitly says: *"Use the exact wording below for all shipping sections. Do not paraphrase."* Also: every template uses "third-party" with hyphen; approved wording uses "third party" without hyphen. And every template uses "8 am–3 pm"; approved is "8am–3pm."

9. **"Reference for usage: [URL]" appears in 15 of 16 Tile Usage sections.** Looks like internal writer notes. Strip before publishing.

10. **The FAQ placeholder allows 4–7 questions; §6.1 mandates a minimum of 6.** Templates say "4-7 questions written for this SKU and the material" — needs to be tightened to "minimum 6 covering: thickness variation, shower floor installation, crazing, cleaning, characteristic features, color mixing across collection."

11. **"Free pickup" wording risks confusion with banned "free shipping."** Every Order & Shipping section starts with *"Free full order pickup is available at our Los Angeles area warehouse..."* This is technically about pickup, not shipping, but it sits in the same neighborhood as the banned "free shipping" phrase (§3.2). Reword to remove "free" if possible: e.g. *"Local clients can collect full orders at our LA warehouse at no additional cost."*

### 🟡 Minor (quality / specificity tightening)

12. **"Wholly unique" appears across many docs** as a loose intensifier. Style Guide §2.1 flags "unique" without context as filler. Replace with the actual variation: color, tone, veining, surface texture.

13. **Chips, pits, and crazing as a trio (§3.1) is rarely the full trio.** Doc 1 says "pits and chips" — missing crazing. Doc 8 names crazing alone. Where the page discusses surface characteristics of a fired clay surface, all three should appear.

14. **"Grout spacing" (banned term, §3.2) appears in Docs 1 and 2.** Each says *"installed edge-to-edge with minimal to no grout spacing."* Replace with "grout joints."

15. **The "About" section currently delivers Installation guidance** (PPE/Prop 65, drywall flush, mitered edges, Schluter strips, sealing). Per §6.1 this content belongs in a separate **Installation and Finishing** section — and About should focus on craft heritage, artisan sourcing, historical context, and color spectrum.
