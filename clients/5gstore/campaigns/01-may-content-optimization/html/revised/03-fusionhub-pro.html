What the Peplink FusionHub Pro Enables

SpeedFusion VPN Hub for Up to 20 Peers

The FusionHub Pro establishes SpeedFusion tunnels between your datacenter or cloud instance and up to 20 remote Peplink devices simultaneously. Each tunnel bonds all available WAN connections at the remote site into a single aggregated pipe back to the hub, combining DSL, LTE, MPLS, fiber, or any mix of connection types into one logical network path.

This SpeedFusion VPN hub approach gives branch offices and remote sites access to combined bandwidth from every available local connection, not just the fastest single link. A site with one DSL line and one LTE connection uses both at the same time rather than holding one in reserve as a failover.

Bandwidth Aggregation Across All WAN Links

FusionHub Pro combines up to 13 WAN links per remote site into a single bonded connection. Remote locations with slow or inconsistent individual connections benefit most from this architecture. A site with three moderate LTE connections aggregates all three into a throughput that a single connection could not match, making video conferencing, large file transfers, and application access reliable in locations where they would otherwise be impractical.

Traffic is distributed at the packet level across all active links simultaneously, so the full bonded capacity is available to every session rather than splitting connections across links.

Session Persistence Through Link Failures

Active sessions stay up even when a WAN link drops. SpeedFusion routes packets across all active tunnels simultaneously, so no session is re-established from scratch during a failover event. VoIP calls, video streams, and database transactions continue without interruption through individual link failures at any remote site connected to the FusionHub Pro.

Expensive 4G/LTE links can be held as hot standby, activating only when primary connections fail, which keeps cellular data costs controlled without sacrificing resilience.

Cloud and Datacenter Deployment

The FusionHub Pro appliance installs on existing server infrastructure across all major platforms. Deploy to a local datacenter, a public cloud, or a hybrid environment without purchasing additional hardware. MSPs can run multiple independent FusionHub Pro instances, giving each customer a dedicated SpeedFusion VPN hub managed separately. All instances are visible and manageable through InControl 2.

Recommended AWS instance sizing for the 20-peer tier is t2.small, which supports 20 peers at up to 200 Mbps throughput. For higher throughput at the same peer count, larger instance types increase capacity.

InControl 2 Management and Client Visibility

InControl 2 provides centralized management across all FusionHub instances and connected Peplink devices. Administrators can view real-time client information, including the domains connected devices are accessing and the applications generating traffic. This data is available as tables, pie charts, or client connection diagrams, giving network administrators visibility into what is running across the SpeedFusion infrastructure.

PrimeCare Device Compatibility

PrimeCare devices connect to an existing FusionHub Pro and do not count against the 20-peer limit. A deployment of 20 standard licensed peers can run alongside any number of PrimeCare devices on the same FusionHub Pro without hitting license ceiling issues, making the Pro tier practical for mixed fleet environments where some devices carry PrimeCare, and others do not.
