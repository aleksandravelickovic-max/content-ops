    3. Terminology — Critical Rules

    3.1 Slots — NEVER use

    **Never use the words "slots" or "slot machines" in any content for The Nash.** The machines operate on Historical Horse Racing (HHR) technology — not traditional random number generators. The terminology distinction is required under New Hampshire charitable gaming regulations.

    | Never use | Always use instead |
    |---|---|
    | slots | gaming machines |
    | slot machines | gaming machines |
    | play the slots | play the gaming machines |
    | slot floor | gaming floor |
    | slot titles | gaming machine titles |

    **What are HHR machines?** Historical Horse Racing machines draw outcomes from a database of past horse races using an algorithm. Unlike traditional slot machines (which use a random number generator), HHR machines blend horse racing data with modern gaming mechanics. This distinction is what allows charitable gaming in New Hampshire. Writers may briefly explain this when relevant — it is a genuine differentiator.

    4. Responsible Gaming — Compliance Rules

    All content must comply with gaming marketing regulations. These are legal and ethical requirements, not optional style choices.

    4.1 Mandatory rules

  • Never use language that suggests guaranteed winnings or implies a strategy will produce consistent profits.

  • Never frame gaming as a financial strategy or income source.

  • Always frame gaming as entertainment.

  • Include responsible gaming messaging in longer-form content, strategy pieces, and any content that discusses betting outcomes.

  • Avoid aggressive gambling hooks, misleading claims, or urgency-based language.

    • 4.2 Required responsible gaming message

    Include this message (or a close paraphrase with all elements present) wherever responsible gaming language is required:

    > **GAMING PROBLEM?** If you are struggling with problem gambling, contact the NH Council on Problem Gambling: Info@NHProblemGambling.org | NHProblemGambling.org | **24/7 Free Confidential Helpline: 603-724-1605 | 1-800-GAMBLER (426-2537)**
