Critical — fix before delivery
Overage recommendation entirely absent §4.9 / §15.2 overage pattern

The piece has multiple sections covering ordering, production runs, and total square footage — but never gives an overage figure. This is a required element wherever ordering guidance appears. Jamie's consistent pattern across Blogs #2, #5, and #6 is:

a minimum overage of 15%... up to 25% for a more uniform result

Add this to the ordering/color batch section where total square footage is discussed. Both figures need context: 15% standard; 25% for the most consistent result across the installation.

"performs reliably" → "performs well" §15.1 Blog #6 Jamie edit

Current line:

Glazed zellige performs reliably as a kitchen backsplash material.

Jamie changed "reliably" to "well" in her Blog #6 edits. This is a confirmed terminology correction, not a style preference. One word swap.

Glazed zellige performs well as a kitchen backsplash material.
Semicolons used as parenthetical separator — must be em-dashes Rule 2.11

Current line in the "Grout and surface care" section:

allowing chips, pits, and crazing; the inherent surface characteristics of hand-fired zellige; to register as texture rather than interruption.

Rule 2.11 is explicit: parenthetical insertions use em-dashes, not semicolons.

allowing chips, pits, and crazing — the inherent surface characteristics of hand-fired zellige — to register as texture rather than interruption.
"Design commentary has noted…" — unnamed attribution Rule 2.8

Current line in the "Format and scale" section:

Design commentary has noted that the square format can read as period-specific when set in a conventional grid.

Rule 2.8: never use unnamed groups making a claim ("Some say," "experts agree," "design commentary has noted"). Make the claim direct or cut it.

The 4x4 square can read as period-specific in a conventional grid — a consideration specifiers should weigh against the project's intended aesthetic register.
Phone extensions are unverified §4.8 / Part 14 no-invention rule

The piece includes:

310-844-1170, Ext. 1 for general questions; Ext. 2 for Trade Program support

The approved contact block specifies info@ziatile.com and 310-844-1170 only. Extensions do not appear in any approved source. Either get client confirmation on the extensions or revert to the standard contact block without them. The line appears once in the "Reaching the specification team" section and references the same number again below — both need to be consistent.

Significant — fix before sign-off
Sample recommendation repeated three to four times §6.3 no information repetition

The piece states that reviewing physical samples is "the most reliable method" in nearly identical language across the color batch section, the grout strategy section, and again in the Trade Program section. §6.3 is explicit: do not repeat the same information in different words across sections. Keep the strongest single instance — the one in the grout strategy section where it's most contextually earned — and reduce all others to a light reference or cut them.

Installer experience note too implicit §15.2 zellige installation requirement

The piece touches on this with "the handmade format does not conform to the tolerances of machine-cut tile" — but §15.2 and the zellige material guard require a direct, explicit statement in the installation section:

zellige requires an installer with specific experience in handmade Moroccan tile.

The current framing implies the requirement without stating it. State it plainly.

Sealing guidance covers grout joints only — incomplete §4.3 sealing rules

The maintenance section currently says:

Sealing the grout joints during installation protects against staining over time.

This only covers grout joints. Per §4.3, sealing applies to all applications including dry spaces, must be stated inline, and should direct to the Installation Guide. Required framing:

Always seal zellige according to our installation instructions, whether in dry spaces or in areas exposed to moisture.

Also verify the zellige installation guide link is present in the live HTML — §9.11 requires it to be hyperlinked wherever referenced.

Cotto Allende mentioned out of context Material specificity

In the "Application scope and climate suitability" section:

Cotto Allende and glazed zellige are not suitable for outdoor freeze/thaw conditions…

This is a zellige article. Cotto Allende has no reason to appear here. State the zellige freeze/thaw rule on its own. Bringing Cotto Allende in introduces material confusion for a reader focused on zellige specification.

"Bell Gardens warehouse" — inconsistent naming, potentially unverified Part 14 no-invention rule

The ordering section says "LA-area warehouse" and the delivery section says "Bell Gardens warehouse in the LA metro." These are inconsistent. More importantly, "Bell Gardens" as a specific facility name doesn't appear in any approved source. If the client has confirmed that location, use it consistently throughout. If not, revert to "LA-area warehouse" in both places.

Installation Guide reference — verify hyperlink is present §9.11

The installation section references a "zellige installation guide" developed for the collection. Per §9.11, every reference to the zellige Installation Guide must be hyperlinked. Verify the link is present in the live HTML. A text reference without a link is incomplete.
