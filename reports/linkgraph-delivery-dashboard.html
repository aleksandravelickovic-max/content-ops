Weekly production flow

Move topics from intake to finished client folders without losing context.

Every client should have a context pack, a monthly deliverables registry, and a Drive-ready export. The dashboard should show what exists, what is waiting, and where the next action belongs.

Import weekly intake

Drop the week's topics and keywords into the intake CSV, then create client/month deliverable registries.

2

Produce in context

Use each client page for voice, offerings, topical terms, source rules, and no-slop writing constraints before drafting.

reports/client-context-dashboard/index.html

Export to Drive

Package the month into a Google Drive-ready folder with client subfolders, manifests, and status summaries.

python3 scripts/build-google-drive-export.py --month YYYY-MM
